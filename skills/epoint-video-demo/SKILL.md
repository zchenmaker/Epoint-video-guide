# 演示视频：文案 + 录屏素材 → 录屏/特效分镜（≤5 分钟）

## 使用者只需看这一段

1. 把本文件（或它所在的压缩包）拖进 AI 对话框。
2. 贴上**已定稿的产品介绍文案**。
3. **顺手把素材一起摊进来——这一步直接决定脚本好不好用**：
   - 系统录屏（文件名 / 时间段 / 录了哪个页面与操作）
   - 产品与业务材料（方案、汇报 PPT、操作手册、功能清单、界面截图、流程图）
   - 政策与图文资料（国家 / 行业政策原文或文件号、标准条款、统计图表、资质证书、客户案例）
   - 有就贴，截图、附件、聊天里的文字都行，**不用整理格式**，文件多时先说一句「以下是全部素材」。
4. 结束。素材没给全也能出脚本，缺的会进「需补录 / 需确认清单」，不会凭空编。

> **素材越全，成片越准。** 这是本包最重要的一条使用前提，不是客套话：
> 只给一段文案，AI 只能排出一堆空镜和套话；把录屏、材料、政策原文、图表一起给足，
> 背景章节才有真实依据、操作句才落得到具体界面、数据镜头才敢上画面。
> 详见第 0.1 节，开工前建议过一遍。

可补一句「5 分钟以内 / 横屏 16:9 / 讲 3 个功能模块」；不补就按下方默认值，**不要连环追问**。
文案还没写好？看第 2 节的骨架。

**本文件自包含**，不需要任何其他文档；另外两份 md 只作备查注意点。
包内 `assets/` 是公司 logo 切片（透明 PNG），片头、章节标题板、片尾落版直接用；工具读不了图片不影响出脚本。
**交付的是一整套可直接用的文件**（提示词 TXT / 一键复制 HTML / CSV / XLSX / SRT / 旁白稿 TXT），不是只有一份 md，见第 8 节。

适用场景：企业级软件产品、业务系统、平台的功能推广——既要展示**真实系统操作录屏**，也要用 **AI 生成的特效/信息图镜头**讲清价值、背景、数据。

## 0 · 这条线是「两种画面拼起来」，不是一张表走到底

| 画面来源 | 谁提供 | 单个镜头时长 | 在脚本里怎么标 |
|---|---|---|---|
| **R · 录屏** | 员工自己录好的系统操作视频 | **6~15 秒** | `[R S03 / 00:12–00:20]` 标到具体素材与入出点 |
| **A · AI 特效** | 要拿去 AI 工具生成的镜头 | **5~15 秒** | `[A]` + 一条可直粘的生成要点（**含运镜**） |
| **T · 模板板** | 剪映模板做的片头尾 / 章节标题板 | **2~4 秒** | `[T]` + 板上文字 |

**A 类为什么只能是 5~15 秒**：主流文生/图生视频单次生成上限很短（即梦文生视频 15 秒、Seedance 约 30 秒、Vidu 8 秒、通义万相 5 秒、Sora 2 约 25 秒，2026-11 公开资料）。把一个抽象句排成 30 秒特效镜头，生成工具根本出不来。所以**一个抽象信息点 = 一个 5~15 秒特效镜头**，多了就拆成连续两个短镜头，并在「AI 特效生成清单」里逐条给生成要点。

和口播包的根本区别：

| | 口播包 | 本包 |
|---|---|---|
| **时长上限** | **≤3 分钟** | **≤5 分钟** |
| 画面主体 | **默认 1 段预设数字人**（3 分钟内整篇一次生成） | 录屏片段 + 多个短 AI 特效镜头 |
| 切镜依据 | 功能模块 + 数字人平台上限 | 操作步数 + 素材 + AI 镜头时长上限 |
| 能否多切 | 不能，接不上 | 可以，剪映里拼接没有连贯性问题 |

### 0.1 · 开工先把素材摊开：给得越全，分镜越准

这条线**不是「给一段文案就能排好片」**。AI 排画面只能依据你给的材料，给少了它只能拿空镜和套话填时间。开工前尽量把这四类都摆出来：

| 素材 | 具体给什么 | 缺了会怎样 |
|---|---|---|
| **系统录屏**（必需） | 按功能模块分段录，每段标「文件名 / 时间段 / 页面名 / 做了什么操作」；先摆好演示数据再录 | 演示视频退化成特效拼贴，只有概念没有真界面 |
| **产品与业务材料** | 方案 / 汇报 PPT / 操作手册 / 功能清单 / 界面截图 / 流程图 / 表单样式 | 菜单路径、按钮名只能写「按实际环境确认」，脚本落不了地 |
| **政策与图文资料** | 国家与行业政策原文或文件号、标准条款、统计年鉴与行业报告图表、资质证书、客户案例 | 背景与痛点章节只剩「响应政策要求」这类空话，站不住 |
| **既有成片与参考** | 过往视频、喜欢的样片、明确不要的做法 | 风格靠猜，返工多 |

- **有多少给多少，不用整理成规范格式**：截图、附件、聊天里的文字一起贴，工具会自己归位。
- 素材多时先说一句「以下是全部素材，先按你看到的排」，避免只读第一条。
- 给不全也能出脚本，但**缺口一律进「需补录 / 需确认清单」，不编**；缺口大的部分，在开头就直说哪一段会空。
- 反过来也要克制：素材必须**可核实、可公开**；客户真名、金额、内部地址、未公开界面先脱敏。

## 1 · 硬约束（先算，再排）

### 1.1 总时长与文案量

- **成片 ≤ 300 秒（5 分钟）**，建议 150~270 秒。片头片尾各 3~5 秒含在内。
- 演示语速 **3.5~4.0 字/秒**且让位于操作节奏；已有成片按「总字数 ÷ 实际时长」反推。
- **旁白字数建议 600~900 字**（不是 300×4=1200 字）：要给录屏操作、页面响应、特效镜头留无旁白的呼吸时间，旁白铺满会变成「念稿配画面」。
- **两个上限不可互换**：口播包 ≤3 分钟、本包 ≤5 分钟；5 分钟是上限不是目标，同一份文案只跑一个包，别把演示的 5 分钟套到口播上。
- 超出 300 秒 → 在「整体建议」给出可裁剪的功能模块与压缩后时长，不硬塞、不加速鼠标。

### 1.2 镜头数与配比

| 项 | 基线 |
|---|---|
| 镜头总数 | 150~300 秒 → **20~40 镜**，平均 7~12 秒/镜；**上限 45 镜**，超过为切碎须写理由 |
| 录屏镜头占比 | **55~70%**（这是演示视频的主体） |
| AI 特效镜头 | 其余，单个 5~15 秒 |
| 模板板 | 片头尾各 1 + 每个章节前 1 块 |
| 功能模块数 | **2~4 个**，超过就建议拆成两条视频 |

### 1.3 章节结构（默认骨架，按文案调整）

| 章节 | 建议时长 | 主要画面 | 作用 |
|---|---|---|---|
| 片头 | 3~5 秒 | T 模板板 | 产品名 / 主题 |
| 背景与痛点 | 15~30 秒 | A 特效（分屏对比 / 示意） | 为什么需要这个产品 |
| 功能概览 | 15~25 秒 | A 特效 + 少量 R | 先给全局 |
| 模块 1 ~ N | 各 30~60 秒 | **R 录屏为主 + A 特效补充** | 真操作、真界面 |
| 价值与成效 | 15~25 秒 | A 特效（数据卡 / 信息图） | 收束 |
| 片尾 | 3~5 秒 | T 模板板 | 落版 |

输出**章节结构表**：`章节 | 时间区间 | 镜头范围 | R/A 镜头数 | 章节标题板文字`，让剪辑的人一眼看清整体。

## 2 · 文案还没定稿？先用这个骨架（可选）

员工只给要点时，**先帮他把要点整理成一版介绍文案，让他确认，再出脚本**（分两步）。

产品推广演示文案骨架（600~900 字）：

1. **一句定位**：产品是什么 / 给谁用
2. **一段背景**：现在怎么做、卡在哪（对应 A 特效镜头）
3. **2~4 个功能模块**：每块写清「进哪个页面 → 做什么操作 → 系统给出什么」——**这一部分是录屏的依据**，写得越具体，素材越好对上
4. **一段价值/成效**：定性表述；没有可核实数据不写数字
5. **一句收束**

铁律：菜单路径、按钮名、页面状态、数据、客户名必须来自员工提供的可核实材料，**一律不编造**；不确定写「按实际演示环境确认（参考：…）」并列入需确认项。

## 3 · 逐句分类表（决定哪句用录屏，必输出）

把文案按分句切开，**每句只给一个标签**：

| 标签 | 识别特征 | 画面来源 |
|---|---|---|
| **O · 操作/功能** | 能说出「点哪里、选什么、打开哪个菜单、提交后页面变成什么样」；含具体功能名 + 动作 | **R 录屏**（必须映射到具体素材） |
| **V · 价值/结论** | 提升效率、压缩空间、留痕、合规、闭环、全覆盖等判断 | **A 特效**（信息图 / 要点板） |
| **B · 背景/痛点** | 传统做法、行业现状、政策要求 | **A 特效**（分屏对比 / 示意） |
| **D · 数据/规格** | 规则条数、模型数量、百分比、系统名称 | **A 特效**（数字动效卡）；除非录屏里真有该界面 |

字段：`句序 | 原句（逐字） | 标签 | 判断理由 | 画面来源 | 素材编号 / 特效编号`

- 「判断理由」写清为什么是 / 不是操作句，让员工能复核。
- **规格数字不是操作**：「106 项检测规则」「811 打分机制」「882 种价格模型」归 D，不硬套录屏。
- **适配性判断**：全文**没有一句**能说出「点哪里、页面变成什么样」→ 这是宣传稿，不是演示文案。在项目信息里明确提示**改用口播包（≤3 分钟）**，或补一段系统操作文案 + 对应录屏素材；仍要出脚本时全部归 V/B/D，并在整体建议再次提示。
- 一个 O 句含两个可独立操作的动作 → 拆两镜，旁白按分句切开，拼接仍逐字等于原文；**一镜一个鼠标主动作**。
- **B 句尽量落到员工给的材料上**：政策原文、行业报告图表、资质证书、方案截图——画面要点写清引用的元素，备注标出处与年份；没有依据的 B 句标「需补材料」，不写成「响应政策要求」。

## 4 · 录屏素材映射表（R 类，必输出）

| 素材编号 | 文件名 / 时间段 | 录了什么（页面 + 操作） | 入点–出点 | 用在哪些分镜 | 状态 |

- 状态只有 **已提供** / **待补录**。
- 每个 R 镜头在总表「画面内容」列写成 `[R S03 / 00:12–00:20] …`，编号与映射表一致。
- 素材缺失时写「待补录：<需要录什么>」，并进**需补录清单**：页面 / 账号与演示数据 / 预置内容 / 建议录制时长 / 脱敏要求。
- 一段素材可被多镜引用（按入出点切），不算重复。
- **R 镜头时长 = max（旁白所需，操作所需）**，宁多留 1 秒给页面响应，不为赶旁白加速鼠标。

**素材充分度判断（写在映射表下方，一句话结论）**：

| 结论 | 判据 | 怎么处理 |
|---|---|---|
| **充足** | 每个功能模块都有对应录屏；背景/价值章节有政策原文、图表或材料可引 | 正常出全套文件 |
| **勉强** | 有录屏但覆盖不全，材料只有文案本身 | 照出脚本，缺镜头的段落标「待补录」，并在整体建议里点名 |
| **不足** | 没有录屏，或只有一段泛泛的文案 | 先提示改用口播包（≤3 分钟），或按清单补素材再跑；仍要出脚本则全部归 V/B/D 并明确告知成片会空 |

- 政策、图表、证书类素材要**标明出处与年份**（文件号 / 报告名 / 发布机构），背景章节引用时照写，不写成「响应国家政策」这类无依据的话。

## 5 · AI 特效生成清单（A 类，必输出）

这是员工拿去「生成镜头视频」的直接依据，逐条可直粘：

| 特效编号 | 对应分镜 | 画面要点（主体 / 元素 / 出现顺序 / 内部小动作，无文字数字） | 运镜 | 时长 | 生成后要叠的字（逐字抄原文） | 备注 |
|---|---|---|---|---|---|---|

- 单条 **5~15 秒**；超过 15 秒必须拆成两条，不要写「一个 30 秒动画」。
- 画面要点写**具体元素**，不用「高端、大气、科技感、震撼」等抽象词，不指定生成工具；**运镜单独成列，写在「运镜」列里，不要混进画面要点**。

### 5.1 运镜提示词（每条 A 镜头必写）

生成工具对「镜头怎么动」比对形容词敏感得多。**每一条 A 镜头都要有一个明确的运镜**，否则出来就是一帧缓缓晃动的静止画面。

| 运镜 | 中文写法（可直接用） | 什么时候用 |
|---|---|---|
| 推近 | 镜头缓慢推近、镜头向主体推进 | 强调一个数据、一个图标、一个结论 |
| 拉远 | 镜头缓慢拉远、由局部拉到全景 | 从细节收束到全局、结尾留白 |
| 横移 | 镜头从左向右平稳横移、平移扫过 | 并列要素逐条亮出、时间轴/流程铺开 |
| 竖移 | 镜头自下而上缓缓升起 | 层层堆叠的结构、从底层到顶层 |
| 摇摄 | 镜头固定机位左右摇、缓慢扫视 | 展示一整片布局、页面/看板全貌 |
| 跟随 | 镜头跟随主体移动、跟拍 | 一个元素穿过流程、数据流向下一环节 |
| 环绕 | 镜头绕主体缓慢环绕 | 单个立体主体、象征性物件（印章、文件、模型） |
| 升降 | 镜头升空俯视、高位俯拍下压 | 开场定调、俯瞰整体场景 |
| 固定 | 镜头固定不动，仅画面内部元素运动 | 信息图、数据卡、并列要点板 |

写法要求：

- **一条只给 1 个主运镜**，最多再加 1 个辅助（如「镜头缓慢推近，同时轻微右移」）；推拉摇移全套上，生成结果必乱。
- 带**速度与幅度**：缓慢 / 平稳 / 轻微，比「炫酷运镜」有用。
- **运镜服务于那句话的意思**：讲体量用拉远或升降，讲细节用推近，讲流程用跟随或横移，讲并列用横移或摇摄。
- **转场不写进提示词**：叠化、擦除、闪白、甩镜这类是剪辑动作，在剪映里做（见第 7 节）。提示词里只写镜头怎么动、画面里有什么。
- 提示词正文的统一结构：`主体 + 元素及其出现顺序 + 画面内部动作 + 运镜 + 光影/质感 + 画面中不出现任何文字、数字、字母和标志，留出后期叠字空间`。

例（数据动效卡，可直接抄结构）：

> 深蓝渐变背景上，三块半透明数据面板自左向右依次浮现，面板内是抽象色块与细线构成的图表轮廓，光点沿着线条流动；镜头从左向右平稳横移，速度缓慢；整体冷色调、干净留白；画面中不出现任何文字、数字、字母和标志，留出后期叠字空间。

### 5.2 其它规则

- **数字与全部中文不交给 AI 生成**：提示词里不出现阿拉伯数字、中文数字、任何文字 / 字幕 / 字母 / 标志，所有文字与数字（如 106 / 811 / 882）一律在剪映后期叠到「生成后要叠的字」列指定的位置。AI 生成的文字必然出错。每条提示词结尾统一加「画面中不出现任何文字、数字、字母和标志，留出后期叠字空间」。
- 「生成后要叠的字」列必须逐字抄原文片段，数字不四舍五入、不补零、不改单位；导出前核对「旁白 / 花字 / 角标」三处数字。
- 数字动效卡里的数字必须与文案一致，不得编造。
- 生成后的视频由员工导入剪映，与 R 片段按总表时间码拼接。
- 片头尾、章节标题板归 T 类，**不进 AI 生成清单**（剪映模板即可，别浪费生成额度）；章节之间想过一段 AI 空镜，则单独列成过场镜头，同样要给运镜，见 7.1。

## 6 · 分镜总表（八字段，公司现行 Excel 表头，顺序不可改）

`分镜序号 | 时间码 | 分镜主题 | 画面内容 | 字幕内容 | 旁白内容 | 音效建议 | 时长（秒）`

- **画面内容**：必须以 `[R …]` / `[A …]` / `[T …]` 开头标来源，再写清屏幕上出现什么文字、图形、数据、出现顺序；**A 镜头末尾补一段 `｜运镜：推近`**，与第 5 节「运镜」列逐字一致，剪辑时一眼能对。
- **旁白内容**：输入文案逐字回填，允许断句加标点，不允许改写增删；各镜头拼起来 == 全文。无旁白的呼吸镜头写「—」并在时长里给足操作时间。
- **字幕内容**：≤15 字/屏，**不得是旁白的连续子串**，要真提炼；数字与专有名词原样保留。
- **时长**：R 录屏 6~15 秒（下限 5 秒，仅当旁白不足 8 字且只有一次点击）；A 特效 5~15 秒；T 模板板 2~5 秒。
- **时间码**：从 0:00 起连续无断点，每行「终点 − 起点 ＝ 时长」，加总 = T ≤ 300 秒（±10%）。不一致时调镜头时长或语速，不删文案。
- 一律 16:9 横屏 1920×1080，录屏不开麦、后期配音。
- 字段填满，不留空、不写「待定」。

## 7 · 标签与转场

标签（剪映后期叠加，不生成视频）：

| 类型 | 何时打 | 位置 |
|---|---|---|
| 章节标题板 | 每个章节开始，1~2 秒全屏 | 全屏 |
| 功能点角标 | 进入某功能模块时，随章节切换 | 左上 |
| 步骤序号 | O 类连续操作镜头，标「1/2/3」 | 右上 |
| 界面标注 | 录屏里需要指的位置（放大镜 / 高亮框 / 箭头） | 画面内 |
| 数据角标 | 念到具体数字时，停留 3~5 秒 | 右侧 |
| 产品 Logo / 落版 | 片头片尾 | 右下 / 全屏 |

转场：

- **章节之间**：用章节标题板兼作转场（1~2 秒），同时完成标签切换。
- **R ↔ A 之间**：0.2~0.3 秒淡入，避免真实界面直接跳到特效画面的突兀感。
- **同一素材内部的连续操作**：直接硬切，不加效果。
- 片头→正片、正片→片尾：淡入淡出 0.3~0.5 秒；全片转场样式统一。

## 7.1 · 过场镜头：要不要 AI 生成、运镜怎么写

「转场」和「过场镜头」是两件事，别混：

| | 是什么 | 谁做 | 提示词 |
|---|---|---|---|
| **转场** | 两个镜头之间的衔接方式（淡入、硬切） | 剪映里加 | **不写进提示词**，写了也生成不出来 |
| **过场镜头** | 两段内容之间插入的一小段独立画面（空镜、示意画面） | 想用 AI 生成就进清单 | **必须配运镜**，见下 |

判断与写法：

- **默认不生成过场**：章节之间用标题板兼作转场（T 类），1~2 秒，最省额度也最稳。
- **确需一段过场**（换主题、换场景、情绪转折、章节之间想留半秒呼吸）→ 列成 `[A]` 过场镜头，2~4 秒，进 AI 生成清单，**运镜一栏不能空**。
- 过场镜头的运镜倾向：**开场/收尾用升降或拉远**，**章节之间用横移或跟随**（有「往前走」的推进感），**单个象征物用环绕**；一段过场里只动一次，别来回。
- 过场镜头**同样不出现任何文字数字**，落版字全部后期叠。
- 一条过场镜头写清三件事：从什么画面开始 → 镜头怎么动 → 停在什么画面。剪辑时前后各有 0.2~0.3 秒淡入淡出即可接上。

## 7.2 · 品牌切片：公司 logo 怎么用（包内 `assets/`）

两个技能包都带同一份 4 张透明 PNG（公司 logo，主色 **#0068B7 蓝 / #E60012 红**）：`epoint-logo-en-white.png`（英文标反白）、`epoint-logo-full-white.png`（全标反白）、`epoint-logo-en.png`（英文标蓝色）、`epoint-logo-full.png`（完整横标蓝色）。

- 片头 / 章节标题板：浅底用蓝色标、深底用反白标，宽度约画面 20~25%、距边 ≥5%，不压章节标题文字。
- 片尾落版：深色底约 3 秒，居中放完整反白标 + 产品名。
- **录屏画面上默认不叠 logo 角标**（会遮界面）；确需常驻时只放右下、避开操作区与界面标注。
- 禁止：拉伸变形、改色、旋转、加描边 / 阴影、裁掉红色飘带、缩到糊掉。
- 输出「**品牌切片使用清单**」：片头 / 每个章节板 / 落版各用哪张文件。AI 工具读不了图片时忽略 `assets/`，按文字规范做同款落版，脚本输出不受影响。

## 8 · 交付：落成成套文件，不是只给一份 md

### 8.1 演示标准 9 件套

每次运行都要**生成文件并保存**；工具不能写文件时，把每份完整内容分别放进代码块、开头标文件名。文件名不绑定任何平台。

| # | 文件名 | 直接给谁用 | 内容 |
|---|---|---|---|
| 1 | `AI特效提示词_直接复制.txt` | AI 视频 / 图片工具 | 每条 A 镜头一条提示词：编号行 + 纯中文正文行，**正文含运镜句**，无数字无文字 |
| 2 | `AI特效提示词_一键复制.html` | 制作人（电脑 / 手机） | 单文件离线、按钮一键复制，顶部「复制全部」；每张卡标出「运镜：推近」；无外部资源 |
| 3 | `旁白稿_直接复制.txt` | 配音 / 文本朗读 | 全片旁白逐字，纯正文无杂字 |
| 4 | `分镜总表_腾讯文档.csv` | 腾讯文档 / Excel / 全员 | 公司现行八字段表头，UTF-8 BOM |
| 5 | `分镜总表.xlsx` | 腾讯文档 / Excel / 全员 | 同 CSV 表格版（能生成才给） |
| 6 | `录屏素材清单_腾讯文档.csv` | 录制人 / 全员 | 素材编号 / 页面 / 操作 / 入出点 / 状态（已录 / 待补录） |
| 7 | `字幕.srt` | 剪映「导入字幕」 | 编号连续、时间码与总表一致 |
| 8 | `分镜数据.json` | 二次加工 | meta / shots / materials / prompts / subtitles / brandAssets |
| 9 | `制作说明.md` | 人看的 | 8.2 所列章节（**唯一的 md**） |

- **CSV / XLSX 表头固定为公司现行八字段**：`分镜序号 | 时间码 | 分镜主题 | 画面内容 | 字幕内容 | 旁白内容 | 音效建议 | 时长（秒）`，顺序不可改；UTF-8 BOM 防乱码，表头加粗、冻结首行。
- **腾讯文档**：把 CSV / XLSX 拖进「新建 → 导入」生成在线表格 → 设「指定人可查看 / 可编辑」→ 链接发群，全员不用装工具就能打开、按列筛选与评论；若所用 AI 工具支持腾讯文档，直接发布成在线表格并把链接写进制作说明.md 开头。含未公开口径数据时先脱敏或只用企业版。
- **一键复制 HTML**：单文件、`<meta charset="utf-8">`、无 CDN / 外部字体，每条提示词一张卡片 + 复制按钮，`navigator.clipboard` + `execCommand` 兜底，点击显示「已复制」2 秒；卡片抬头写「编号 + 运镜」，复制内容只有提示词正文，不带编号与运镜标签；页首写明「数字与中文不交给 AI 生成，后期叠字」。
- **SRT / JSON / 旁白 TXT** 规范同口播包第 8.3 节；所有文件里的数字、时间码、原文逐字一致。

### 8.2 制作说明.md 里应包含的章节（人看的部分）

1. **项目信息**：类型＝演示（录屏 + AI 特效）、字数、T（≤300 秒）、章节数 / 功能模块数、**R/A 镜头数与占比**、素材清单核对结果、**素材充分度结论（充足 / 勉强 / 不足）**、适配性判断、本次假设
2. **章节结构表**
3. **逐句分类表**
4. **录屏素材映射表**（表下附一句素材充分度结论与主要缺口）
5. **AI 特效生成清单**（含「运镜」列，逐条都能直接生成）
6. **分镜总表**（八字段）
7. **逐镜头详情**：R 镜头给前置状态 / 操作 / 结束状态 / 界面标注 / 操作路径 / 备选；A 镜头给画面元素、**运镜**与文字出现顺序；T 板给板上文字
8. **旁白稿 + SRT 字幕稿**（编号连续，时间码与总表一致）
9. **需补录清单 / 需确认项**
10. **片头片尾文案 + 剪映加工清单**（拼 R → 插 A → 章节板 → 叠标签 → 导入 SRT → 字幕校对 → 导出）+ 整体建议
11. **品牌切片使用清单**（片头 / 章节板 / 落版各用哪张 logo）
12. **注意点**（备查，不参与生成）

## 9 · 自检后再输出

- **T ≤ 300 秒**；镜头数 20~40（≤45）；**R 占比 55~70%**；功能模块 2~4 个
- 每个 O 句都映射到具体素材编号或标为待补录；**没有凭空录屏**
- V / B / D 句未被硬套成录屏；规格数字没有被当成操作
- 每条 A 特效 5~15 秒、有可直粘的画面要点；**「运镜」列已填，且只有 1 个主运镜**（最多 1 个辅助）；超 15 秒已拆条；T 板未混入生成清单
- 过场镜头若列入清单：时长 2~4 秒、运镜已给、无文字数字；叠化 / 擦除 / 闪白等转场词未混进提示词
- 运镜都在提示词正文里出现，且用可执行的中文说法（推近 / 拉远 / 横移 / 竖移 / 摇摄 / 跟随 / 环绕 / 升降 / 固定），没写成「电影感运镜」「炫酷转场」这类空词
- **素材充分度已给结论**（充足 / 勉强 / 不足）；政策、图表、证书类引用标了出处与年份，背景章节没有「响应国家政策」这类无依据的空话；缺口全部进需补录清单
- 旁白逐字 == 原文，无改写、无遗漏；无旁白镜头已给足操作时间
- 时间码从 0:00 连续，差值＝时长，加总闭合 ±10%
- 每条字幕 ≤15 字且不是旁白连续子串
- R 镜头有前置/操作/结束状态，≥5 秒，一镜一个鼠标主动作
- 素材编号、特效编号在分类表 / 映射表 / 生成清单 / 总表 / 详情里一致
- 章节边界有标题板；R↔A 有淡入；同素材内硬切
- 画面具体到可执行，无抽象形容词、无工具绑定；运镜写得可执行，不是形容词堆砌
- 品牌切片清单齐备：片头 / 章节板 / 落版各指定了 `assets/` 里的具体文件，录屏上未叠 logo 角标
- **交付文件齐备**：提示词 TXT / 一键复制 HTML / 旁白稿 TXT / 八字段 CSV / SRT / JSON / 制作说明.md 已落盘或完整给出；XLSX 能生成则给
- **提示词合规**：纯中文、无阿拉伯数字与中文数字、无文字 / 字母 / 标志描述、结尾有「后期叠字」句；106 / 811 / 882 等数字与全部中文只在「生成后要叠的字」与后期图层出现
- **腾讯文档路径已写明**：导入步骤或有在线表格链接；CSV 为 UTF-8 BOM、八字段表头顺序未改
- 字段填满，需确认项集中在末尾；已给出脱敏与合规提醒

## 10 · 注意点（备查，不参与生成）

- **品牌资产**：logo 只用包内 `assets/` 的 4 张切片，不重绘、不改色、不拆字；对外发布前按公司 VI 最新规范复核。
- **字体**：全片 ≤2 种，只用可商用白名单——思源黑体 / 思源宋体、阿里巴巴普惠体 3.0、HarmonyOS Sans、MiSans、霞鹜文楷、得意黑、站酷系列、企业已采购字体。不用微软雅黑、苹方、方正 / 汉仪 / 华文商业字库，也不用来源不明的「免费字体合集」；授权以官方最新声明为准，对外项目留存凭证。
- **数据**：录屏优先用测试环境数据；真实客户名、金额、账号、内部 URL 必须打码；涉密内容优先公司企业版 / 私有部署 / 本地模型，未公开系统界面不上公网 AI 对话。
- **素材**：AI 生成的特效画面、配乐、音效、图标、图片需能举证商用授权；各生成工具单次时长与商用条款以官方最新说明为准。
- **素材越全越准**：录屏、材料、政策原文、图表给得越全，脚本越具体。宁可多给让工具自己筛，不要只丢一段文案就催结果；确实没有的直说「没有」，让它进需补录清单，而不是让工具猜。
- **运镜克制**：一条镜头一个主运镜、速度慢、幅度小。企业软件演示的运镜是稳住画面、引导视线，不是炫技。**录屏本身不生成运镜**——要强调某个按钮，用剪映关键帧小幅推近或加高亮框，别把真界面丢给 AI 重画。
- **不编造**：文案里没有的数据、案例、客户名不往画面里加；菜单路径不确定列入需确认项。
- **备查文档**：《视频分镜脚本标准说明.md》《视频制作框架说明.md》只供查阅，不是运行依赖；口径有分歧时以本文件为准。
- **数字与中文不交给 AI 生成**：所有数字、产品名、文案中文都在剪映后期叠字；交给生成模型必然错字错数。
- 输出为**成套制作文件**：录屏、AI 特效素材生成与剪映后期由制作人自行完成。
